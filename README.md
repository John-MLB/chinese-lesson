# chinese-lesson
國語科備課｜國小四、五年級老師補充教材

## 觸控筆記（2026-11-17）

課文維持 95px 標楷體。課文及老師補充視窗的左右兩側都有畫筆、橡皮擦、存檔；補充內容切換及關閉鈕亦左右各一組。

- 畫筆：手繪、直線、四種顏色、三種粗細；橡皮擦擦除整筆。誤寫或誤擦可直接按左右兩側的「上一步」，要重做則按「下一步」。
- 輕點畫筆即可用紅色、手繪、細筆書寫，按鈕會變深綠色；再輕點一次即回滑鼠模式，可點課文註記、捲動解說內容。長按畫筆約 0.6 秒可開啟設定盒，調整顏色、粗細與直線。返回滑鼠後再次輕點畫筆，會重新使用紅色手繪細筆。翻頁也會回到操作模式。
- 筆跡自動保存在目前電腦的此瀏覽器。清除網站資料、換瀏覽器或換電腦不會帶走這份自動記錄，請另存檔案。
- 「下載筆記到本機」匯出可重新編輯的 JSON 筆記，不是課文圖片；「開啟筆記檔」可載入。載入會取代目前筆跡，操作前有提示，載入後仍可復原。
- 「存到同步資料夾」呼叫瀏覽器原生存檔視窗，請選電腦上已設定同步的 Google Drive 或 OneDrive 資料夾。網站不直接登入雲端；雲端上傳及衝突處理由桌面同步程式負責。網站僅確認檔案寫入成功，不能確認雲端同步狀態。
- 若瀏覽器不支援或阻擋直接存檔，請用下載按鈕，再把檔案放入同步資料夾。預設檔名含時間，方便保留不同版本。

課文筆跡以字元位置定位；解說筆跡依內容區塊定位，捲動時會一起移動。不同螢幕換行可能不同，精細圈字建議在教室相同解析度再次確認。每份筆記上限為 5,000 筆及 150,000 個座標點；瀏覽器儲存空間不足會提示另存檔案。

## 檢查

執行 `node ink.test.cjs`，檢查筆記格式往返、無效資料拒絕和橡皮擦幾何判定。網站不需要建置步驟，直接由 GitHub Pages 提供根目錄檔案。

### 快捷操作更新

- 課文與補充視窗的左右工具列都有「上一步／下一步」，書寫中也能直接撤回／重做，保留當時的書寫模式。
- 畫筆長按設定支援觸控筆、手指、滑鼠；滑動離開按鈕會取消長按。鍵盤焦點在畫筆按鈕時，可按方向鍵下開設定。
- 網站顯示普通白色箭頭；滑鼠移動時跟著移動，觸控的滑鼠模式則標示最近觸碰位置。
